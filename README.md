# **Pioneer N-50A DLNA Network Controller**

A modern, fast, and responsive web interface (controller) for managing the **Pioneer N-50A** network audio player in DMR (Digital Media Renderer) mode. The project is designed to be deployed on a single-board computer (e.g., Orange Pi Zero 3\) and provides seamless integration with a media server (MiniDLNA on a Keenetic router).

## **🚀 Key Features**

* **Dual-screen UI:** Minimalist and clean design, separated into a library browser and a full-featured playback screen (*Now Playing*).  
* **DLNA Browser:** Fast navigation through media server directories with support for deep folder nesting and proper metadata display.  
* **Album Art Parsing:** A robust metadata parser that automatically extracts original album covers (\<upnp:albumArtURI\>) from Keenetic's MiniDLNA to display on the controlling device.  
* **Smart Timeline (Seek):** Real-time display of the current track time and total duration with precise seeking via a slider (full support for FLAC/MP3).  
* **Software Pause (Workaround):** The Pioneer N-50A firmware blocks standard pause commands for heavy formats (DSD/DSF) in DMR mode, returning a 500 error. This project solves this at the logic level: when pausing, the app remembers the current second and sends a physical Stop to the player. Upon resuming, it instantly reloads the track, performs a hidden Seek, and triggers Play.  
* **Single Point of Control (Takeover):** A WebSocket-based (Socket.io) control model restricted to a single active connection. When a new remote connects (e.g., a Pixel Tablet connecting after a Pixel 8 Pro), the previous device is automatically disconnected and locked with a warning to prevent cross-conflicting SOAP requests to the player.  
* **PWA Support (Progressive Web App):** Integrated manifest.json and a background Service Worker allowing the controller to be installed as a native app on Android 13-16 devices without the browser address bar.  
* **24/7 Fault Tolerance:** Full integration with the PM2 process manager for automatic server startup on Linux boot and recovery upon accidental crashes.

## **🛠 Tech Stack**

* **Backend:** Node.js, Express (static file serving), Socket.io (real-time bidirectional communication), Axios (UPnP/AVTransport SOAP requests).  
* **Frontend:** Vanilla JS (ES6+), HTML5, CSS3 (variables, responsive design, view transition animations).  
* **Parsing:** fast-xml-parser for handling heavy XML responses from ContentDirectory.

## **⚙️ Setup and Installation**

### **1\. Clone the repository and install dependencies**

git clone git@github.com:YOUR\_USERNAME/pioneer-dlna-controller.git  
cd pioneer-dlna-controller  
npm install

### **2\. Configure IP Addresses**

Before starting, ensure that the actual IP addresses of your local network are set in the files:

* In dlnaService.js and inspect\_dlna.js: The DLNA\_URL variable should point to your router/server (e.g., http://192.168.1.1:8200/ctl/ContentDir).  
* In server.js and inspect\_pioneer.js: The RENDERER\_URL variable should point to your Pioneer network player (e.g., http://192.168.1.129:8080/AVTransport/ctrl).

### **3\. Run in Development Mode**

node server.js

The interface will be available on your local network at http://\<ORANGE\_PI\_IP\>:3000.

### **4\. Setup Autostart (Production)**

For continuous background operation, use PM2:

sudo npm install \-g pm2  
pm2 start server.js \--name "pioneer"  
pm2 save  
pm2 startup

*Copy and execute the command generated by pm2 startup to integrate the manager into the systemd initialization system.*

## **📱 Installation as an App (PWA)**

For mobile devices (e.g., Google Pixel / Pixel Tablet):

1. Open Google Chrome and navigate to http://\<ORANGE\_PI\_IP\>:3000.  
2. Open the browser menu (three dots) and select **"Install app"** (or "Add to Home screen").  
3. *Workaround for unsecure HTTP on Android 13+:* If the app stubbornly opens as a tab, go to chrome://flags/\#unsafely-treat-insecure-origin-as-secure in Chrome, add your address http://\<ORANGE\_PI\_IP\>:3000 to the text field, switch the value to Enabled, and click **Relaunch**. Reinstall the app afterward.
